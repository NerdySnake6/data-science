# DataScience

Две лабораторные по дисциплине «Основы Data Science», адаптированные Igor Kalinin.

## Лабораторные

- [ЛР1 — Ames Housing](lab1/README.md): подготовка данных, регрессия, анализ остатков и кросс-валидация.
- [ЛР2 — Линейная алгебра](lab2/README.md): векторы, матрицы, системы уравнений, PCA и SVD.

## Быстрый запуск

Требуется Python 3.10 или новее. Из корня проекта:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e ./lab1 -e ./lab2
jupyter notebook
```

В Windows используйте `python` вместо `python3` и активируйте окружение командой `.venv\Scripts\Activate.ps1`.

Откройте `lab1/notebooks/LR1_Ames_SelfStudy.ipynb` или `lab2/linear-algebra-lab.ipynb` и выполните ячейки сверху вниз. Демонстрационные данные уже включены.
